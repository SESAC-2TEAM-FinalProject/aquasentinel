# ADR — 아키텍처 결정 기록

되돌리기 어렵거나, 나중에 "왜 이렇게 했지" 가 반드시 나올 결정을 한 건에 한 장씩 남긴다.

**🔴 `docs/` 가 아니라 여기에 두는 이유** — `docs/` 는 `.gitignore` 되어 있다(팀 내부 공유 문서, 메신저로 전달). ADR 은 **코드가 가리키는 기록**이라 코드와 같이 버전이 올라가야 한다. `runbooks/` 와 같은 이유다.

## 쓰는 법

- 파일명: `NNNN-짧은-제목.md` (번호는 이어서)
- 최소 칸: **맥락**(지금 코드·실물이 어떤지, 실측으로) · **결정** · **왜** · **대가** · **기각한 대안** · **재검토 조건**
- 🔴 **실측과 추론을 가른다** — `[사실]`/`[추론]`/`[제안]` 를 붙인다. 숫자는 명령과 함께 적어 나중에 다시 잴 수 있게 한다
- 결정을 뒤집을 때는 **지우지 말고** 새 ADR 을 쓰고 이 표의 상태를 `대체됨(→ NNNN)` 으로 바꾼다
